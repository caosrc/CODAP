name: CPTEC Nowcasting
description: Portal atual do CPTEC e limites de integração com os mapas.
---

O endereço antigo do SCOPE (`https://sigma.cptec.inpe.br/scope`) retornou HTTP 410 em 15 de novembro de 2026. O portal atual `https://nowcasting.cptec.inpe.br/` apresenta produtos de nowcasting para 60, 120 e 180 minutos; não foi encontrada documentação pública de API ou tiles para sobreposição no mapa.

**Why:** Evita apontar para o SCOPE aposentado ou representar uma previsão externa como observação dentro do mapa.

**How to apply:** Use o portal atual como link externo até o CPTEC documentar um serviço de dados integrável; sempre identifique os horizontes como previsão.
